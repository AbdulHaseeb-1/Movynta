Assistant tool demos

Each card shows one tool: the request the assistant sends, the result it gets back, and a picture drawn from that result. Every example uses one sample scene: a figure with two arms, a crate and an empty group, at revision 12. The reference for each tool is in docs/tools/.

Checked by tests means the backend suite (apps/backend/src/modules/tools/tool-docs.spec.ts) runs the real tool code on this sample and compares the output with the result shown here. Live editor means the output is made by the connected desktop editor (mesh geometry, material data, rendered pictures, measurements and applied history), so the example shows the shape of the result only.
